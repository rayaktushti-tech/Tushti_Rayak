Gaming & Care Platform for Dementia Patients

Cognitive Stimulation, Memory Games & Caregiver Monitoring

As Team Leader at the Smart India Hackathon (SIH), I led the creation of an empathetic web application designed to support dementia patients. The system combines neuro-stimulating memory games to exercise cognition alongside a caregiver support suite with routines, medication alerts, and panic prompts.

Key Highlights & Features:

  • Cognitive Stimulation Games: Gentle memory matching, sensory pattern recall, and reaction exercises.
  • Caregiver Portal: Real-time medicine logs, routine checklists, and easy distress monitoring.
  • Gentle Sensory UI: High-contrast readable typography, soothing color tones, and zero clutter to prevent anxiety.
  • Leadership: Directed project scope, team coordination, and system integration within SIH guidelines.
